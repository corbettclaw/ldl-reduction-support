Getting started

Choose Rehearsal and tap Launch to run the scripted, offline demo. Tap Flood, then a road or building tile, and run again to see how the specialists respond. Open Rules to understand the fixed demo targets.

Live mode

Live requires your own OpenRouter API key, a compatible model ID, and internet access. Save the key in Settings, select Live, then confirm the data-sharing and possible charges before each run. Set a spending limit for the key in your OpenRouter account. For OpenRouter billing or model availability, use OpenRouter Support.

Data and privacy

Use Reset city to replace the local city and Delete key in Settings to remove the saved credential. Exports include the mission and discussion, so review them before sharing. See the Swarm City Privacy Policy.
